# Privacy Policy

Twitter Likes to Obsidian saves liked posts from X/Twitter to the user's own Obsidian vault.

## Data Processed

The extension may process:

- X/Twitter liked post text, author names, handles, timestamps, URLs, images, video thumbnails, quoted post details, reply context, and article card metadata.
- The user's Obsidian Local REST API key.
- Local extension state such as session statistics and retry queue items.

## How Data Is Used

Data is used only to save liked posts as Markdown notes and media files in the user's Obsidian vault through the Obsidian Local REST API.

## Data Storage

The Obsidian API key is stored in Chrome extension storage.

Captured post data may be stored temporarily in Chrome extension local storage if saving fails, so the extension can retry later.

Saved Markdown notes and media files are stored in the user's Obsidian vault.

## Data Sharing

The extension does not sell, share, or transfer user data to the developer or third parties.

The extension communicates only with:

- X/Twitter pages and media hosts needed to read liked posts and media.
- `http://127.0.0.1:27123`, the user's local Obsidian Local REST API endpoint.

## Remote Servers

The extension does not use a companion server and does not send user data to developer-operated servers.

## User Control

Users can remove saved data by deleting notes and media from their Obsidian vault.

Users can remove extension data, including the API key and retry queue, by removing the extension or clearing its Chrome extension storage.

## Contact

For questions, open an issue on this project's GitHub repository.
